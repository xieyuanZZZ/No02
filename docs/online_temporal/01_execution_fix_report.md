## 1. 实际修复

| 项 | 旧问题 | 本轮处理 |
|---|---|---|
| MPC Δu 代价 | `u_prev` 被从每个相邻差分中减去 | `D` 首行只作用 `u_0`；`H/f` 与 `explicit_cost` 一致；随机梯度/目标测试 |
| 制动/停车 | 随机暂停把当前位置设为目标，非零速度不能保证停住 | `request_stop_at(s_target)`：`s_target-s_act >= v²/(2a_brake)+v·dt_ctrl+margin` 才接受；拒绝原因可统计 |
| 等待来源 | 随机暂停与计划等待混用 `_hold_kind`，无来源区分 | `source=random|online`；在线/随机等待分别计时；BRAKE/HOLD 时新命令拒绝 |
| 候选停车点 | 无接口 | `feasible_stop_candidates()`：未越过、非计划等待点、非终点、刹得住 |
| 连续碰撞 | 4 点采样 | `dt_dyn` 子步级相对运动解析最小距离 + 二次方程首次越界；初始重叠/切阈值/零相对位移测试 |
| 航点到达 | 5 cm 球 | 弧长跨越检测并插值；一次控制步跨多个航点全记录；`MonotoneProgress` 历史邻域 |
| 终止状态 | 碰撞/完成混在一起 | `collision / safe_completion / timeout / time_censored / infeasible_stops / mpc_failures / controller_failed / degraded_control` 分开 |
| 在线日志 | 无 | `coordinator_stats`（mean/P50/P95/P99/max、超 0.4 s 次数、异常数），`coordinator_log`（动作/接受/拒绝原因/风险前后） |

**明确未改**：Diffusion 权重、几何路径、W2+ 目标/预算、`d_safe=0.35`、H=32、MPC 默认速度/加速度界。

## 4. 与“旧结果”的区别

- 旧 `docs/Online_FirstHit_P0-P2` 的 D2 数字来自错误 Δu 代价/制动振荡/4 点碰撞；本表全部来自修复后代码和新随机暂停目标（`s+brake+lead+margin`），**不可直接与旧表混用**。
- 本轮 N4 W2+ 的碰撞率仍明显低于原始计划，但 p=0 不再保证 0 碰撞（`open_crossing_300000_n4_0` 计划本身余量仅 0.341 m）。
- `safe_completion` 不包含静态障碍；静态障碍单独报告。

---

## 5. 局限

- MPC 仍是平面双积分器，不含航向/差速约束；
- “可停车”只做开环制动距离筛选，实际闭环可行性由仿真检验；闭环仍可能出现停短/越过（记录 `arrival_shortfall`/`infeasible_stops`）；
- 在线协调首版只允许“增加等待”，不提前恢复、不改变几何；
- 本报告只证明执行基础可用于在线实验，**不证明任何在线方法的安全性**。
