# MPD MPC 执行与 First-Hit 模型误差分析

**日期**：2026-11-04
**分支**：`experiment/mpc-execution-firsthit`
**冻结基线**：标签 `baseline/pre-mpc-execution`（commit `13f8fc6`）
**动力学**：二维点质量双积分器（**只做平面平移**，无航向/差速/转向）

## 0. 一页结论

| 问题 | 回答 |
|---|---|
| MPC 是否真正跑通 | **是**。单机 8/8 场景完成，约束零违规、QP 零失败；RMSE 0.036–0.242 m |
| 原计划 vs W2+ 在 MPC 下的碰撞率 | N=2 p=0.1：**14.6% vs 2.1%**；N=4 p=0.1：**60.4% vs 47.9%** |
| 相对理想离散执行，安全性变化 | **一致性变差**：N=4 的 W2+ 从 6.2% 涨到 **47.9%**（+41.7 pp） |
| 完成时间变化 | **膨胀 1.05–1.39 倍**（p 越大越明显） |
| 原 First-Hit 预测误差 | 对理想 MC：MAE **0.041**；对 MPC MC：MAE **0.083**（**误差翻倍**） |
| 误差主要来源 | **制动/重启造成的时序漂移**（不是跟踪误差，RMSE 仅 0.1 m 量级） |
| 下一步改 First-Hit 的方向 | 先做**段通行时间的状态相关分布**，再考虑把速度/模式并入状态 |

**一句话**：First-Hit DP 对理想执行模型是准的（MAE 0.041、排序相关 0.77），
但换成真实动力学后**误差翻倍、排序相关性掉到 0.69**，而且在 N=4 上把"看起来有效"的 W2+ 收益
从 93.8% 安全完成率打到 52.1%。

## 1. 动力学模型与控制器

### 1.1 双积分器

```
x = [px, py, vx, vy]^T,  u = [ax, ay]^T
x_{k+1} = A x_k + B u_k
```

参数（`MPCSimConfig`）：

| 参数 | 值 |
|---|---|
| MPC 控制周期 | 0.1 s |
| 动力学仿真周期 | 0.05 s |
| 上层时序周期 | 0.4 s |
| 预测时域 | 18 步 |
| v_max / a_max / a_brake | 1.5 m/s / 2.0 m/s² / 2.0 m/s² |
| d_safe | 0.35 m |

### 1.2 约束的保守多边形近似

`‖u‖₂ ≤ a_max` 用内接 L1 球近似：`|ax| + |ay| ≤ a_max`。
因为 `‖u‖₂ ≤ ‖u‖₁`，满足 L1 约束必然满足欧氏约束——**保守但绝不越界**。
实测轴对齐时 `‖a‖₂ = 2.00`，对角时 `‖a‖₂ = 1.414`（L1 顶点），符合设计。

### 1.3 MPC

标准线性 MPC，OSQP 求解：

```
min Σ (x−xref)'Q(x−xref) + u'Ru + Δu'SΔu + 终端项
s.t. |ax|+|ay| ≤ a_max,  |vx|+|vy| ≤ v_max
```

决策变量 2×18 = 36 维，单次求解 ≈ 0.5–1 ms。
**MPC 不做多机器人避碰、不修改他人时序**——安全收益必须归因于 First-Hit 调度。

### 1.4 路径时间参数化（本轮最关键的工程点）

**不能直接复用理想执行时间。** 最初版本只做梯形速度规划，结果 p=0 也撞：
离散模型假设"每时隙推进一个航点"，短段机器人（0.2 m/段）在 MPC 里会以接近 v_max 的速度
**抢跑**，相对时序被破坏。

修正：从离散调度表 `t_k = (k + Σw)·Δt` 反推每段的平均速度
`v_sched = Δs_k / Δt_k`，把它作为**速度上限**注入剖面：

- 允许更慢（物理受限时自然变慢）；
- 不允许更快（防止抢跑、防止追赶绝对时间表）。

修正后 p=0 的最小间距从 0.000 m 恢复到 **0.350 / 0.452 / 0.368 / 0.541 m**（d_safe=0.35）。

## 3. 多机器人 MPC 执行对照（阶段 4）

**设置**：N=2 取 6 个冻结任务、N=4 取 6 个，p ∈ {0, 0.1, 0.2}，每格 **8 次 MC**，
同一任务/同一等待计划/同一种子配对比较。总耗时 8.0 min。

### 3.1 碰撞率

| 组 | 计划 | p=0 理想 → MPC | p=0.1 理想 → MPC | p=0.2 理想 → MPC |
|---|---|---|---:|---:|
| N=2 | 原始等待 | 0.0% → 0.0% | 6.2% → **14.6%** | 6.2% → **14.6%** |
| N=2 | W2+ | 0.0% → 0.0% | 0.0% → **2.1%** | 2.1% → **12.5%** |
| N=4 | 原始等待 | 0.0% → **16.7%** | 54.2% → **60.4%** | 77.1% → **81.2%** |
| N=4 | W2+ | 0.0% → 0.0% | 6.2% → **47.9%** | 39.6% → **60.4%** |

### 3.2 安全完成率

| 组 | 计划 | p=0.1 理想 → MPC | p=0.2 理想 → MPC |
|---|---|---|---:|
| N=2 | 原始 | 93.8% → 85.4% | 93.8% → 85.4% |
| N=2 | W2+ | 100% → 97.9% | 97.9% → 87.5% |
| N=4 | 原始 | 45.8% → 39.6% | 22.9% → 18.8% |
| N=4 | W2+ | 93.8% → **52.1%** | 60.4% → 37.5% |

### 3.3 完成时间与制动开销

| 组 | 计划 | p=0 | p=0.1 | p=0.2 |
|---|---|---:|---:|---:|
| N=2 | 原始 | 1.07× | 1.23× | 1.29× |
| N=2 | W2+ | 1.09× | 1.25× | 1.31× |
| N=4 | 原始 | 1.05× | 1.24× | 1.36× |
| N=4 | W2+ | 1.12× | 1.27× | 1.39× |

（倍数 = MPC 完成时间 / 理想完成时间。）

制动开销（p=0.2，**按每台机器人**）：N=2 约 6.1 s / 22.4 s（27%），
N=4 约 6.2 s / 26.3 s（24%）。CSV 中的 `extra_brake_s` 是**四台求和**，需除以 N。

### 3.4 关键发现

1. **W2+ 的收益在 MPC 下大幅缩水**：N=4、p=0.1 时，理想模型里 W2+ 把碰撞率从 54.2% 压到 6.2%，
   MPC 里只压到 47.9%——**收益从 −48 pp 缩到 −12.5 pp**。
2. **N=4 原计划在 p=0 就出现 16.7% 碰撞**：冻结库的 p=0 最小间距是 0.355 m，
   只比 d_safe 高 0.005 m，MPC 的连续运动轻易吃掉这点余量。
3. **N=2 依然稳健**：p=0 全安全，W2+ 在 p=0.1 只有 2.1%，说明模型失配随机器人数放大。

## 4. First-Hit 预测误差（阶段 5，本轮核心）

**设置**：N=2 取 4 个任务、N=4 取 4 个，p ∈ {0.1, 0.2}，每格 12 次 MC，
按**两两机器人对**统计（N=4 有 6 对）。共 112 个对数样本。

| 对照 | MAE | 偏差 | RMSE | Spearman ρ |
|---|---:|---:|---:|---:|
| **DP vs 理想 MC** | **0.0412** | +0.0126 | 0.0694 | **0.770** |
| **DP vs MPC MC** | **0.0826** | −0.0112 | 0.1339 | **0.686** |
| 理想 MC vs MPC MC | 0.0938 | −0.0238 | 0.1439 | 0.472 |

分 p：

| p | DP vs 理想 MAE / 偏差 | DP vs MPC MAE / 偏差 |
|---:|---|---|
| 0.1 | 0.0240 / +0.0017 | 0.0708 / **−0.0236** |
| 0.2 | 0.0584 / +0.0236 | 0.0944 / +0.0012 |

### 4.1 四个必答问题

**问题一：MPC 会让 First-Hit 系统性高估还是低估？**

**低估，但幅度不大（−1.1 pp 总体；p=0.1 时 −2.4 pp），真正的损失是精度而非偏差**：
MAE 从 0.041 翻倍到 0.083，排序相关性从 0.77 掉到 0.69。
换句话说，DP 对"哪一对更危险"的判断变差了约 10%，但总体概率没有系统性偏移。

**问题二：速度和暂停状态是否明显影响下一段执行时间？**

**是，非常明显**。完成时间膨胀 1.05–1.39 倍，且随 p 单调增加：
p=0 时 1.05–1.12×（纯加减速开销），p=0.2 时 1.29–1.39×（制动+重启主导）。
每台机器人在 p=0.2 下有约 6 s 花在制动上，占总完成时间 24–27%。

**问题三：简单调整每段平均执行时间能否修正大部分误差？**

**能修正一部分，但不够。** 证据：
- 完成时间的膨胀系数（1.23–1.39）可以直接作为段时长的乘子注入 DP；
- 但排序相关性从 0.77 掉到 0.69 说明"相对危险程度"的排序本身变了，
  单纯统一放大所有段的时间**不会**改变相对排序——因此只能修正幅度、不能修正排序。

> **本轮没有重跑"膨胀时间后的 DP"来验证这一点**（时间不足），这是下一轮必须补的第一个实验。

**问题四：是否需要把速度和暂停阶段显式引入 First-Hit 状态？**

**建议引入，但用轻量方式**。理由：
- 排序退化说明"同一段在不同速度/模式下耗时不同"确实影响风险；
- 但全连续状态 DP 会爆炸。

推荐两步走（与实施安排 §九一致）：
1. **先标定** `P(Δt_segment | v, μ, ℓ, p)`：从 MPC 仿真里统计"段通行时间"的经验分布，
   按速度分箱（如 0/0.5/1.0/1.5 m/s）与模式（正常/制动/重启）；
2. **再升级**为半马尔可夫进度模型：状态仍是段索引 + 一个速度分箱，转移时间是采样得到的分布，
   而不是固定的 1 个时隙。

## 9. First-Hit 修改建议（下一步）

按优先级：

1. **补做"段时长膨胀"实验**（半天工作量）：把每段名义时长乘以 MPC 实测膨胀系数
   （1.23–1.39，按 p 分档），重跑 DP vs MPC MC 的 MAE/ρ。
   如果 MAE 明显下降而 ρ 不变，说明只需时间缩放；如果 ρ 仍低，必须做状态相关模型。
2. **标定段通行时间分布**：从 MPC 仿真中记录每段的实际耗时，按速度分箱统计分布，
   作为半马尔可夫进度模型的转移核。
3. **把"是否正在制动"作为一个二值状态**加入，而不是完整连续状态——这是成本最低、
   信息量最大的一维扩展。
4. 在上述验证完成前，**不要**实现在线风险触发重调度。

**结论边界**：本轮证明了"理想执行模型会显著高估调度收益"（N=4 的 W2+ 收益从 −48 pp 缩到 −12.5 pp），
也证明了 First-Hit DP 本身是正确的（对理想模型 MAE 0.041）。
但**没有**证明"改哪一项最有效"——这需要第 1 项补做实验。
