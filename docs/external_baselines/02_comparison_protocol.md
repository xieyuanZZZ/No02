# 02 统一对比协议（冻结版）

**状态**：协议已固定；**统一 MPC 对照尚未启动**，原因见 `01_reproduction.md` 和
`03_pilot_results.md`。本文件不包含任何伪造的对比数字。

---

## 1. 方法分组

主实验必须比较：

1. `raw_wait`：原始等待；
2. `offline_w2plus`：冻结的离线整数搜索（历史参数 p=0.1 优化版本保留）；
3. `offline_w2plus_current_p`：按当前测试 p 重新优化的公平版本（新增，不覆盖历史）；
4. `firsthit_online`：冻结的实时 First-Hit 在线调整；
5. `offline_plus_firsthit`：冻结的离线 W2+ + 在线 First-Hit（主方法）；
6. `switchable_edge`：Switchable-Edge Search；
7. `winktpg`：WinkTPG；
8. `stpg`：STPG（适配完成后再加入）。

外部方法先保留**原生复现结果**，再单独报告“接入统一 MPC 后”的结果；不得把两者混在一个
均值里，也不得为了公平删掉对方的核心机制。

---

## 2. 第一轮场景

- 20 个 N4 任务、10 张地图；
- p = 0 / 0.05 / 0.1 / 0.2；
- 暂停时长 0.4 s；
- 每任务/概率 50 个独立随机种子；
- 同一任务/种子配对；
- 全部通过 No02 的 MPC 双积分执行器；
- 同 `d_safe=0.35`、同碰撞检测、同成功/超时定义。

**几何有效子集**：先建立与算法无关的“路径不穿静态障碍”子集；主表同时给完整 20 任务
和有效子集，禁止按成绩删场景。

---

## 3. 外部方法接入的统一接口

每个适配器必须提供：

```text
input:
  paths[N,H,2]        冻结路径
  wait0[N,H-1]        初始等待（整数时隙）
  pause_events        仅由仿真器持有的随机暂停表（适配器不可读未来）
  dt_slot=0.4, d_safe=0.35, MPC 参数
output:
  per-slot actions:
    robot, kind={stop_at, release, speed_profile}, target_s, duration_s
  native metadata: upstream commit, build, mode, runtime
```

**约束**：

- 适配器只能通过执行器的 `request_stop_at()` / 释放接口改变时序；
  不得直接改机器人位置或速度；
- 若原方法本身输出速度剖面，允许映射为执行器的参考速度，但必须保留原生结果；
- 适配器不得读取 `pause_events` 的未来项；
- 所有动作必须经过执行器可行性检查，拒绝原因要统计。

---

## 4. 指标

- 机器人间碰撞率；
- 静态障碍碰撞率（单独）；
- 总体安全完成率（全员到达、无碰撞、无超时、无控制失败）；
- Makespan；成功任务完成时间；
- 计划/随机/在线等待；
- 在线计算 mean/P95/P99、超 0.4 s 次数；
- 离线计算时间；
- MPC 失败、不可行停车、超时、死锁；
- 最小安全间距。

按 `(task_id, p, seed)` 配对；95% CI 以任务为聚类单位；补充按地图分组。

---

## 5. 适配器的语义保持检查

在任何正式对比前必须通过：

1. 官方示例原样复现（已完成，见 `01_reproduction.md`）；
2. 输入转换后，原方法输出的顺序/等待/速度剖面能被重新执行；
3. 把转换结果喂回原方法，冲突顺序与原始输出一致（或给出可解释差异）；
4. 在 2 个 N4 任务、p=0.1、3 个种子上做 smoke，检查不可行停车/超时/单位错误；
5. 与 No02 执行器闭环后，不出现“原方法动作被静默丢弃”。

未通过 1–5，不进入 50-seed 正式实验。
