## 6. 复现指令

```powershell
# 0) 恢复到冻结状态
git checkout baseline/n4-wait-before-w2plus

# 1) 阶段一：构建 N=2 轨迹库（需先由 WSL 侧生成候选）
.\.venv\Scripts\python.exe scripts\mpd_s1_build_plan_bank.py

# 2) 阶段二：延迟冲突验证
.\.venv\Scripts\python.exe scripts\mpd_s2_delay_analysis.py

# 3) 阶段三（N=2）正式实验
.\.venv\Scripts\python.exe scripts\mpd_s3_wait_optimization.py --agents 2 `
    --n-mc-eval 400 --n-mc-dev 200 `
    --eval-seeds "20261120,20261121,20261122" --out results/MPD_S3_wait/final

# 4) N=4 轨迹库与正式实验
.\.venv\Scripts\python.exe scripts\mpd_n4_build_plan_bank.py
.\.venv\Scripts\python.exe scripts\mpd_s3_wait_optimization.py --agents 4 `
    --n-mc-eval 300 --n-mc-dev 200 `
    --eval-seeds "20261130,20261131,20261132" --out results/MPD_N4_wait/final

# 5) 测试
.\.venv\Scripts\python.exe -m pytest tests -q
```

MPD 候选生成（WSL）：

```bash
bash /mnt/d/mpd_official/wsl_setup/gen_candidates.sh --tasks-per-map 8 \
     --out /mnt/d/mpd_official/results_mpd/plan_candidates2
```

## 8. 当前主要结论（冻结时的状态）

| 结论 | 数值 |
|---|---|
| 随机暂停确实造成碰撞（N=2） | p=0.1 碰撞率 8.73%，p=0.2 13.13% |
| DP 与 MC 一致性 | r=0.998，MAE=0.0044 |
| N=2：W3 vs 强基线 W2 | +0.36 pp，95% CI [−0.23, +1.28]，**不显著** |
| N=4：W3 vs 强基线 W2 | **+20.35 pp**，[+13.04, +29.35]，**显著** |
| N=4：p=0.2 残余碰撞 | 37.80%（W3） |
| N=4：固定 Δw 是否 p=0 安全 | **否**（1/2/3/5/8 均有 20%–30% 确定性碰撞） |
