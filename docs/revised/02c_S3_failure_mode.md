# S3 补充诊断：单障碍绕行为何失败

## 证据

| 场景 | 任务数 | 参考路径绕行比 | 生成路径绕行比 | 静态安全率 |
|---|---:|---:|---:|---:|
| 开放交叉 | 25 | 1.001 | 1.003 | 0.960 |
| 单障碍绕行 | 25 | 1.070 | 1.056 | 0.270 |
| 单瓶颈通行 | 25 | 1.000 | 1.001 | 0.995 |

绕行比 = 路径长度 / 起终点直线距离；1.000 表示完全笔直。

## 解读

- 参考路径在单障碍场景的绕行比为 1.070，而生成路径只有 1.056，说明模型几乎总是输出近直线，直接穿过障碍。
- 交叉场景参考绕行比 1.001，本身就是直线，所以模型表现好；瓶颈场景参考绕行比 1.000，虽然要过门但整体仍接近直线。
- 结论：**模型学到的是「起点到终点的准直线插值」，没有学到「绕开障碍」**。
  这是表示/训练问题，不是地图分辨率问题（S2 已证明三种分辨率无差异）。
