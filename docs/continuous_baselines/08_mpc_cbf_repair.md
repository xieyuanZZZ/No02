# 08 MPC-CBF 修复报告

## 已修复

1. **终点记录**：改为动态 positions/velocities/times 列表；每个控制步执行后立即保存
   新状态，再检查 `goal_error<0.25`、`|v|<0.25`；完成时间取 `times[-1]`。
   不再出现“内部完成但返回未到达”。
2. **零填充碰撞**：只对实际执行的有效轨迹做连续子步碰撞检查。
3. **动力学一致**：优化与实际执行均为半隐式 Euler
   `v+=a dt; p+=v dt`。
4. **暂停**：求解器第一步把暂停机器人控制约束为受限制动；实际不再用 `u=0` 覆盖。
5. **路径推进**：改为在下一段路径上单调投影，避免全局最近点跳段。
6. **到达**：使用终点位置和终端速度，而非仅 waypoint index。
