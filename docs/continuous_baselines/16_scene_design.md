# 16 credible_v1 场景设计

**目录**：`results/Continuous_Baseline_Comparison/credible_v1/`

## 场景清单（6 个任务，N=4）

| 任务 | 类型 | 几何 |
|---|---|---|
| `A1_open_orthogonal` | 开阔交叉 | 四个方向正交，中心交叉 |
| `A2_open_diagonal` | 开阔交叉 | 两条对角线对向交叉 |
| `B1_block_below_above` | 静态障碍 | 中央 1.6×1.6 矩形；上下左右绕行 |
| `B2_block_cross` | 静态障碍 | 同上，路径更靠外侧 |
| `C1_corridor_4way` | 狭窄走廊 | 0.56 m 宽走廊；四机器人从四角汇入单通道 |
| `C2_corridor_pair` | 狭窄走廊 | 0.56 m 宽走廊；两对机器人对向 |

- 地图 10×10 m；
- 机器人半径 0.15 m，静态净空 0.03 m；
- 共同 `d_safe=0.35`、`vmax=1.5`、`amax=2.0`；
- 路径 32 点；
- 所有任务在评测前固定，未按结果筛选。

## 几何验证

`scene_validation.json` 记录：

- 起点/终点最小间距 >0.35 m；
- 路径到矩形/圆形障碍净空 >=0.20 m；
- 每条路径长度。

**限制**：场景 C 的 0.56 m 通道按“单机器人可通过、两个机器人不能并排”
设计；实际安全评价还需考虑机器人跟踪横向误差，本轮 pilot 已发现部分方法
擦墙/碰撞，说明通道几何对跟踪误差很敏感，不能直接作为最终论文场景。

## 路径来源

本轮使用**共同的、显式给定的无碰撞参考路径**，不是冻结 Diffusion 新生成路径。
因此对比的是固定路径在线执行，不是完整规划能力；Ours 的 Diffusion 规划能力
不在本场景表中。
