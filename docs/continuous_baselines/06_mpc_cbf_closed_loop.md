# 06 闭环验证：多机器人 MPC-CBF

**日期**：2026-11-06  
**结果**：`results/Continuous_Baseline_Comparison/pilot/mpc_cbf/`

## 实现与修复

`src/fhd/adapters/mpc_cbf_adapter.py` 是独立控制器，不调用冻结 No02 MPC：

- 双积分器 `[x,y,vx,vy]`，控制 `[ax,ay]`；
- 时域 4 步，`dt=0.1 s`；
- 硬约束 `|v|<=1.5`、`|a|<=2.0`；
- 每对机器人加入离散 CBF `h_{k+1} >= (1-gamma)h_k`；
- **修复零填充碰撞**：只对 `valid_end` 有效轨迹计算，不再把未执行零当重合；
- **修复积分不一致**：优化与实际都使用半隐式 Euler
  `v_{k+1}=v_k+a dt`、`p_{k+1}=p_k+v_{k+1}dt`；
- **暂停**：控制器把当前暂停机器人第一步控制约束为受限制动，
  实际执行不再用 `u=0` 覆盖；记录不可行/求解失败；
- **路径推进**：改为在下一段路径上单调投影，不再用全局最近点跳段；
- 到达判定用实际终点距离和终端速度，而不是仅靠 waypoint 索引。

仍不够好，不能因为“无碰撞”就判为安全完成。

## 仍存在的问题

- 目标 lookahead 与 CBF 时域导致机器人可能停在路径中间；
- CBF 仅用位置约束，双积分器相对阶二，可能需要相对速度/制动项；
- 暂停时求解器第一步制动约束可能导致其余时域不可行/保守；
- N4 P95 ~60 ms，尚未做预构建/warm-start；
- 没有静态障碍；没有 N6/N8。

## 结论

当前状态：**ADAPTED，未 VERIFIED**。零填充和动力学一致性错误已修复，N2/N4 可运行且
无假碰撞，但完成率不达标，不能作为正式论文对比结果。
